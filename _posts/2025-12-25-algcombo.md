## Introduction

Symmetric functions are combinatorial objects which are useful for encoding enumerative information in a way which can be manipulated algebraically. We will look at how to build symmetric functions, what it means to evaluate these polynomials over different bases, and will also work out an example application in graph theory. Then, we will look at symmetric polynomials generated from Young Tableaux, and will examine how these relate to classifying irreducible representations of the symmetric group $S_n$.

\section{Symmetric Functions}

To build up to polynomials, first we will define a smaller building block...

> <u>Defn</u>: A **monomial** is a 1-term polynomial in  $n$ variables. If $\mathbf{x}=(x_1, x_2,..., x_n)$ and $\mathbf{a} = (a_1, a_2,..., a_n)$, we denote the monomial in vector notation as:
> <p style="text-align: center;"> $\mathbf{x}^{\mathbf{a}} = x_1^{a_1}x_2^{a_2}...x_n^{a_n}$ </p>

Why is this a combinatorial object? We can think of a monomial as a partition of an integer: 
<p style="text-align: center;">$\sum_{i=1}^{n}a_n = a_1+a_2+...+a_n$</p>

> <u>Defn</u>: By a *partition* of some $n \in \mathbb{N}$, we are referring to a list $\lambda=(\lambda_1, \lambda_2, ..., \lambda_k)$ such that $\lambda \vdash n$, meaning:
> <p style="text-align: center;">$\sum_{i=1}^{k} \lambda_i = n$</p>

> <u>Example</u>: Let's see how these ideas relate. For example, consider the monomial in 4 variables, $x_1^2x_2^3x_3x_4^6$. This corresponds to a partition of 12, namely $\lambda=(2,3,1,6) \vdash 12$. Questions such as enumerating all possible size $k$ partitions of some number can be answered using combinatorial methods.

Another way we can view this object combinatorially is through the permutations of its variables. We can consider swapping the variables $x_1$ and $x_2$ in the previous example, resulting in the change: $$x_1^2x_2^3x_3x_4^6 \xrightarrow{}x_2^2x_1^3x_3x_4^6 $$ This corresponds to a group action of $S_n$. Later, we will further explore the idea of how $S_n$ can be more deeply represented by polynomials. For now, let's see how this can be viewed as an action.

> <u>Defn</u>: An \textbf{action} of a group $G$ over some set $X$ is a function $\sigma: G \times X \xrightarrow{}X$ satisfying two properties:
> 1. Identity: If $e$ is the identity element of $G$, $\sigma(e,x)=x$.
> 2. Compatibility: $\forall g_1, g_2 \in G, \ \sigma(g_1, \sigma(g_2,x)) = \sigma(g_1g_2,x)$.

The convention is to write the action as a mapping to permutations of the exponents rather than the variables, but this becomes a bit confusing, so we will ignore convention. Given monomials $m=x_1^{a_1}x_2^{a_2}...x_n^{a_n}$ and elements $\sigma \in S_n$, let's define the action of $S_n$ on the set of $n$-variable monomials to be: 

<p style="text-align: center;">$\sigma \cdot m = x_{\sigma(1)}^{a_1}x_{\sigma(2)}^{a_2}...x_{\sigma(n)}^{a_n}$</p>

Now, define a **polynomial** to be a function of $n$ variables, built from a sum of some number of *monomials* in $n$ variables. Then, the action of $S_n$ on the set of $n$-variable polynomials can be defined based on the action of $S_n$ on each individual monomial terms in the sum. The set of all symmetric polynomials in $n$ variables forms a ring for any $n$, which we will denote as $\Lambda^n$.
 
## Bases for $\Lambda^n$

Given this ring of symmetric polynomials, a natural idea is to think about what a basis might look like. One possible basis can be constructed by considering all monomials in which the exponents of the variables correspond to a given partition of the total degree $k$. We call these objects \textbf{monomial symmetric polynomials}. Using vector notation for the set of variables and the set of exponents as before, we can denote: 
<p style="text-align: center;">$m_{\lambda}(\mathbf{x}) = \sum_{(a_1a_2...a_n) \vdash k} \mathbf{x}^{\mathbf{a}}$</p>

For example, if $\lambda=(2,1,1)$, we have:
<p style="text-align: center;">$m_{211} = x_1^2x_2x_3+x_1x_2^2x_3+x_1x_2x_3^2$</p>

The set of monomial symmetric polynomials in $n$ variables forms a basis for $\Lambda^n$. This makes sense intuitively, because if we include some monomial term in a symmetric polynomial, we also need to include all other terms where the variables are permuted in order to preserve symmetry.

\underline{Defn}: Using these objects, we can construct another basis. We define the \\ \textbf{elementary symmetric polynomials} $e_{\lambda}$ using the following conditions: 
\begin{enumerate}
\item[\textbullet] If $\lambda=(\lambda_1,\lambda_2,...\lambda_l)$, then $e_{\lambda}=e_{\lambda_1}e_{\lambda_2}...e_{\lambda_l}$
\item[\textbullet] If $n \in \mathbb{N}$, $e_n=m_{11..1 \ \vdash\lambda}$
\end{enumerate}

\underline{Ex}: Note that we can easily write an expression of elementary symmetric polynomials in terms of monomial symmetric polynomials. Consider $e_{\lambda}$ for $\lambda=(2,1)$.
\[
\begin{aligned}
e_{21} &= e_2 e_1 = (x_1x_2 + x_1x_3 + x_2x_3 + \cdots)(x_1 + x_2 + x_3 + \cdots) \\
       &= (x_1^2x_2 + x_1^2x_3 + \cdots) + (x_1x_2^2 + x_2^2x_3 + \cdots) + (x_1x_2x_3 + \cdots) \\ 
       &= m_{21}+m_{111}
\end{aligned}
\]
\medskip 

The set of elementary symmetric polynomials in $n$ variables also forms a basis for $\Lambda^n$. We can prove this by observing that the change of basis matrix from elementary symmetric polynomials to monomial symmetric polynomials is upper triangular, and is therefore invertible. \medskip

## Application: Graph Theory

One motivation of looking at bases over these polynomials is determining information about their structure based on the coefficients we get. A way in which we can see how this works is through a method of extracting information from graphs using proper colorings. \medskip 

\underline{Defn:} A proper $k$-coloring of a graph $G=(V,E)$ is a function $\kappa:V \rightarrow S \subset \mathbb{N}$ such that if $uv \in E$, then $\kappa(u) \ne \kappa(v)$, and $|S| = k$.
\begin{enumerate}
\item[\textbullet] The subset $S$ of $\mathbb{N}$ represents the possible set of distinct colors which we can assign to vertices.
\end{enumerate}

The minimal number of colors in which we can color some graph, and the number of ways in which we can do so, gives insight to its structure. For example, as we add edges to a graph, it becomes more difficult to construct a proper coloring with a small set of colors. We can extend the idea of chromatic number by compiling the data from all possible $k$-colorings. \medskip 

\underline{Defn}: The Chromatic Symmetric Function (CSF) $X(G)$ of some graph $G$ is the sum over all monomials generated by $k$-colorings of the graph, where the exponent of each $x_i$ corresponds to the number of appearances of the color $i$.  \medskip 
\newline

\underline{Ex}: $G=S_4$. Then, $X(G)$ can be separated into cases based on the number of possible colors used in the subset. $$(x_1^3x_2+x_1^3x_3+x_1x_2^3+x_1x_3^3)$$
$$+{4 \choose 2} (x_1^2x_2x_3+x_1x_2^2x_3+ x_1x_2x_3^2+x_1^2x_2x_4+x_1x_2^2x_4...)$$
$$+4!(x_1x_2x_3x_4)$$

Note that for the case of 3 colors, we multiply each coloring monomial by $4 \choose 2 = 6$ since we need to choose which 2 of the 4 color options are the ones which are repeated in the outer vertices. For the case of 4 colors, we multiply the monomials by $4!$ since we can permute the vertex colors in any way. But this expression is equivalent to: $$m_{31}+ {4 \choose 2}m_{211}+(4!)m_{1111}$$

Since we can express this in terms of monomial symmetric functions, we can also express it in terms of the elementary basis. This can be useful in a few ways:

\begin{enumerate}
\item[\textbullet] Distinguishing graphs based on their corresponding CSFs (conjectured by Stanley to fully distinguish trees).
\item[\textbullet] [Stanley-Stembridge Thm] Characterizing which structural properties in a graph lead to fully positive coefficients over the elementary basis.
\end{enumerate}

\section{Young Tableaux}

A tableau is a combinatorial object that we can use to add nuance to the idea of a partition. First, let's examine its simpler counterpart. \medskip 

\underline{Defn}: A \textbf{Young Diagram} (YD) is a collection of boxes which are left-justified and have the property that the number of boxes in each row is weakly decreasing. For example:
\[
\ydiagram{4,3,3,2}
\]

We can see that this diagram corresponds to the partition $\lambda=(4,3,3,2) \vdash 12$. Such partitions are used to refer to the ``shape" of a diagram, and we can define the ``size" of a diagram to be the total number of boxes it contains. \medskip

\underline{Defn}: Given some partition $\lambda$, a \textbf{Semi-Standard Young Tableau} (SSYT) $T$ is a filling of a Young Diagram of shape $\lambda$ using elements from $\mathbf{N}$, such that the following conditions hold (we will index elements similarly to elements in matrices, except starting from the upper left corner):
\begin{enumerate}
\item[\textbullet] Elements along rows weakly increase: $\forall i, \ j_1<j_2 \implies T_{i,j_1} \le T_{i,j_2}$
\item[\textbullet] Elements along columns strictly increase: $\forall j, \ i_1<i_2 \implies T_{i_1,j} < T_{i_2,j}$
\item[\textbullet] We call some SSYT of size $n$ a ``Standard Young Tableau" (SYT) if all $\{1,2,...,n\}$ appear exactly once in the filling. Below are examples of an SSYT and a similar SYT, both of shape $\lambda=(4,3,2)$.
\end{enumerate}

\[
\begin{ytableau}
       \ 1 & 2  & 2  & 3 & \none \\
        \ 2 & 3 & 5 & \none \\
        \ 6 & 6
\end{ytableau}
\begin{ytableau}
       \ 1 & 3  & 5  & 6 & \none \\
        \ 2 & 7 & 8 & \none \\
        \ 4 & 9
\end{ytableau}
\]

Given some tableau $T$, we can define a monomial $x^T$ in $m$ variables, where the variables represent the elements which appear in $T$. Let the number of times some number $i$ appears in $T$ be $\#(i)$, then define: $$x^T = \prod_{i=1}^m x_i^{\#(i)}$$

\underline{Defn}: Given some tableau shape $\lambda$, we can define its \textbf{Schur polynomial} $s_{\lambda}$ in $m$ variables as the sum over all such monomials over possible SSYT of shape $\lambda$, where the number of distinct elements ranges from 1 to $m$. $$s_{\lambda}(x_1,x_2,...,x_m) = \sum x^T$$

\underline{Ex}: Consider $s_{\lambda}(x_1,x_2,x_3)$ for $\lambda=(3,2)$. To compute this, we draw every possible SSYT of this shape, where the elements in the boxes are chosen from $\{1,2,3\}$.

\[
\begin{ytableau}
       \ 1 & 1  & 1 & \none \\
        \ 2 & 2
\end{ytableau}
\begin{ytableau}
       \ 1 & 1  & 1 & \none \\
        \ 3 & 3
\end{ytableau}
\begin{ytableau}
       \ 1 & 1  & 1 & \none \\
        \ 2 & 3
\end{ytableau}
\begin{ytableau}
       \ 1 & 1  & 2 & \none \\
        \ 2 & 2
\end{ytableau}
...
\]
\medskip 

\begin{spacing}{1.1}Resulting in: $s_{\lambda} = x_1^3 + x_1^3x_3^2+x_1^3x_2x_3+x_1^2x_2^3+x_1^2x_3^3+2x_1^2x_2x_3^2+2x_1^2x_2^2x_3+x_1x_2x_3^3+2x_1x_2^2x_3^2+x_1x_2^3x_3+x_2^2x_3^3+x_2^3x_3^2$.
\end{spacing}
\medskip

It turns out that in general, Schur polynomials over some partition $\lambda$ are both symmetric as we have previously defined, and also form a basis for the ring of symmetric polynomials $\Lambda^n$.


## Representations of $S_n$

Let's pause and consider group representations. 

\underline{Defn}: Given a group $G$, a \textbf{representation} of $G$ is a vector space $V$ together with a homomorphism $\sigma: G \rightarrow GL(V)$. This condition can also be thought of as a linear action of $G$ on $V$, defined as $g \cdot v = \sigma(g)(v)$. \medskip 

\underline{Defn}: A subspace $W$ of $V$ is a \textbf{subrepresentation} if $W$ is invariant under the action of $G$. We call a subrepresentation \textbf{irreducible} if it has no nontrivial subrepresentations. \medskip

\underline{Ex}: Consider a representation of $S_3$ over $\mathbb{C}$, call the homomorphism $\sigma$, where:

$$\sigma(\epsilon) = \left[\begin{array}{cccc}
1 & 0 & 0	\\
0 & 1 & 0 \\
0 & 0 & 1
\end{array}\right] \ \ 
\sigma(1 2) = \left[\begin{array}{cccc}
0 & 1 & 0	\\
1 & 0 & 0 \\
0 & 0 & 1
\end{array}\right] \ \ 
\sigma(1 3) = \left[\begin{array}{cccc}
0 & 0 & 1	\\
0 & 1 & 0 \\
1 & 0 & 0
\end{array}\right] $$

$$\sigma(2 3) = \left[\begin{array}{cccc}
1 & 0 & 0	\\
0 & 0 & 1 \\
0 & 1 & 0
\end{array}\right] \ 
\sigma(1 2 3) = \left[\begin{array}{cccc}
0 & 0 & 1	\\
1 & 0 & 0 \\
0 & 1 & 0
\end{array}\right] \ 
\sigma(1 3 2) = \left[\begin{array}{cccc}
0 & 1 & 0	\\
1 & 0 & 0 \\
0 & 1 & 0
\end{array}\right] \ 
$$
 

A powerful fact from representation theory is that in any group, the number of conjugacy classes is equal to the number of irreducible representations of the group. In the case of $S_n$, this correlation can be explicitly shown through Young Tableau. \medskip 

First, we claim that the number of conjugacy classes in $S_n$ is the same as the number of cycle types, since two elements which are conjugates also have the same cycle type. \medskip 

\underline{Pf}: First consider some $\alpha \in S_n$ with cycle type $(k_1,k_2,...,k_l)$, meaning \\ $\alpha=\alpha_1\alpha_2...\alpha_l$ where each $\alpha_i$ is a cycle of length $k_i$. \medskip

Then consider any element in the same conjugacy class of $\alpha$, which can be expressed as $\tau\alpha\tau^{-1}$ for some $\tau \in S_n$, we can write: $$\tau(\alpha_1\alpha_2...\alpha_l)\tau^{-1} = (\tau\alpha_1\tau^{-1})(\tau\alpha_2\tau^{-1})...(\tau\alpha_l\tau^{-1})$$

We can easily show that each of these individual conjugates $\tau\alpha_i\tau^{-1}$ will have the same cycle length as $\alpha_i$. Therefore, the original conjugate will have the same cycle type as $\alpha$. We will leave the other direction of the proof as an exercise. \medskip

This is an exciting result because the possible cycle types of $S_n$ correspond to ways in which we can partition $n$, which then correspond to Young Tableau with $n$ boxes.

\section{Tabloids and Modules}

To relate representations of the symmetric group back to tableaux, we need to think about a slightly less restrictive object. \medskip 

\underline{Defn}: A \textbf{tabloid} $\{T\}$ is an equivalence class of fillings of a Young Diagram, in which equivalence is based on the rows of the diagram containing the same set of numbers. We will denote $R_T$ and $C_T$ as the row and column stabilizers, respectively. We will also define the vector space of all tabloids of shape $\lambda$ to be $M^{\lambda}$.
\medskip 

\underline{Defn}: We define a \textbf{polytabloid} as enforcing symmetry over colummns: $$v_T = \sum_{q \in C_T}sgn(q)\{q \cdot T\}$$

As every polytabloid is a tabloid, we can define a module: \medskip 

\underline{Defn}: A Specht Module $S^{\lambda}$ is a subspace of $M^{\lambda}$ spanned by elements $v_T$: $$S^{\lambda} = span_{\mathbb{C}}\{v_T | \text{$T$ is a Young Tableau of shape $\lambda$}\}$$

We can use these modules to construct the irreducible representations of $S_n$. \medskip 

\underline{Ex}: Consider $S_3$. Then the module $S^{(3)}$ corresponds to the tabloid:

\[
\begin{ytableau}
       \ 1 & 2 & 3
\end{ytableau}
\]
Which corresponds to the trivial representation of $S_3$ (homomorphism is the identity function), as the actions of $S_3$ permute row entries, thus the polytabloid is fixed. The module $S^{(111)}$ corresponds to the tabloid: 
\[
\begin{ytableau}
       \ 1 & \none \\
       \ 2 & \none \\
       \ 3 & \none
\end{ytableau}
\]
Which corresponds to the alternating representation of $S_n$ (homomorphism is the sign function).


\underline{Exercise}: Convince yourself that the findings of the above example holds in general for $S_n$.
\medskip

\underline{Sidenote}: One last interesting comment is that we can connect these different objects constructed from the idea of Young Tableaux. The fact that Specht modules correspond to irreducible representations is analogous to the fact that Schur polynomials form a basis over the ring of symmetric polynomials. This mapping is done through the Frobenius character map: $$Ch: R^n \rightarrow \Lambda^n$$where $R^n$ is the representation ring of $S^n$ and $\Lambda^n$ is the ring of symmetric functions in $n$ variables. This function maps irreducible representations $S^{\lambda}$ of $S_n$ to Schur polynomials $s_{\lambda}$ for the same $\lambda$.
